# Senior CPU PyTorch Labs

`labs.json` is the authored lesson/contract index. Reference implementations live
in `Pythilo/PythonRuntime/pythilo_runtime/labcode/<id>.practice.answer.py`.
Run `python3 scripts/generate-research-content.py` to regenerate the two courses,
starter scaffolds, Lab metadata and native registration module. Every contract
runs against learner code; the renderer never substitutes the worked answer.

All fixtures are local and explicitly synthetic. These experiments test training
and evaluation mechanics, not production model quality or GPU/distributed speed.
